# Exploratory Data Analysis (EDA) Using Python

## Project Overview
This project explores sample sales data using Python. It identifies missing values, cleans the dataset, summarizes sales, and analyzes monthly trends.

## Tools Used
- Python
- Pandas
- Matplotlib

## Key Tasks
- Checked missing values in the dataset.
- Filled missing sales values using the median.
- Handled missing product and region values.
- Analyzed sales by product.
- Analyzed monthly sales trends.
- Created line and bar charts.
- Exported cleaned data and analysis results.

## Dataset
A sample sales dataset created for learning and demonstration purposes.

## How to Run
1. Install the required packages:
   `python -m pip install pandas matplotlib`
2. Run the project:
   `python eda_analysis.py`

## Outputs
The output folder contains the cleaned dataset, missing-value summary, sales summaries, and charts.
